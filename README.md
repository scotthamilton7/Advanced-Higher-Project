# Advanced-Higher-Project
Job application website created for 2024 SQA Advanced Higher Computing Science qualification.

## Features

* **User Authentication**: Registration and login for both applicants and businesses
* **Job Search**: Applicants can filter available jobs by type and location
* **Applicants Overview**: Businesses can view a list of each applicant along with their CV for a posted role

## Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (Server-side logic and session management)
* **Database:** MySQL / phpMyAdmin

## How to Run Locally

1. Clone the repository
2. Move the project folder to your local server directory (e.g., `XAMPP/htdocs`).
3. Import the `database.sql` file via phpMyAdmin.
4. Update configuration files with your local database credentials.
5. Open `localhost/Advanced-Higher-Project` in your browser.
